# データソース

「どの県が、何にエネルギーを使っているか」探索ダッシュボードのための、データソースとデータ層の設計。
調査日: 2026-10-02。シート名・行コード・列コード・年度は、公式 xlsx 47 本すべてを openpyxl で読み、同じ構造であることを確認済み。

## 1. 結論

一次ソースは資源エネルギー庁「都道府県別エネルギー消費統計」（政府統計コード `00551006`）。
2023年度（暫定値）と2022年度の公表（2025-12-25）で、2026-01-16 に訂正された版。

- 掲載ページ: https://www.enecho.meti.go.jp/statistics/energy_consumption/ec002/results.html
- ファイル（47 県まとめ）: https://www.enecho.meti.go.jp/statistics/energy_consumption/ec002/xls/20260116_all.zip
- 調査の概要: https://www.enecho.meti.go.jp/statistics/energy_consumption/ec002/summary.html
- Q&A: https://www.enecho.meti.go.jp/statistics/energy_consumption/ec002/faq.html

出典表記: 資源エネルギー庁「都道府県別エネルギー消費統計」。

### 統計の性格（公式の説明から）

- 総合エネルギー統計の最終消費のうち、企業・事業所他、家庭、運輸（家庭の乗用車）を、一次統計（石油等消費動態統計、エネルギー消費統計、家計調査、県民経済計算など）で 47 県に分割した推計。
- 発電などのエネルギー転換と、運輸（家計の乗用車を除く。貨物、鉄道・バス・タクシーなど）は対象外。
- 47 県の和は総合エネルギー統計の全国値と一致しない（Q&A B-1。最大の要因は、本統計が最終消費ではなく投入ベースで計上しているため）。
- 1991〜2004 年度と 2006 年度は推計されていない（Q&A D-1）。
- 事業用水力・原子力は県へ配分できないので常に 0（Q&A F-1）。
- 暫定値は県民経済計算の当該年度が未公表のため前年度値で推計しており、家庭の電力と運輸の値が確報で変わる（Q&A A-2）。

### 取得

enecho.meti.go.jp は AWS WAF の JavaScript チャレンジを返すため、curl では zip を受け取れないことがある。
`npm run fetch` は取得を試み、受け取ったものが zip（先頭 `PK`）でなければ手順を表示して止まる。ブラウザで落として `data/raw/` に置けば、再実行で `data/raw/xlsx/` に展開する。
zip 内の東京都のファイルは、個別に公開されている `13tokyo.xlsx` と同一（SHA-1 一致）。

### 改訂

2022年度の公表時（2024-12-27）に、作成方法を一部改訂して 1990 年度まで遡って改訂された。
年度を足すときは差分ではなく、新しい zip から全系列を作り直す。

## 2. シートと採用

県ごとに1ファイル（`01hokkaidou.xlsx` 〜 `47okinawa.xlsx`）。どのファイルも同じシート構成。

| シート | 内容 | 採用 |
| --- | --- | --- |
| `90FY` `05FY` `07FY` … `23FY` | 年度ごとの表。業種 × エネルギー種 | エネルギー単位表（TJ）を配信 |
| `石炭` … `総計` | エネルギー種ごとの時系列 | 不採用（年度シートと同じ値） |
| `指標` | 1人あたり・県内総生産あたり | 人口（配信）、1人あたり（照合） |

### 年度シート

1 シートに3つのブロックが縦に並ぶ: 固有単位表、エネルギー単位表（TJ）、炭素単位表（t-C）。
D 列の「ｴﾈﾙｷﾞｰ単位表」から「炭素単位表」の手前までをエネルギー単位表として読む。
行は A 列の行コード、列は 1 行目の列コードで引く。A1 に「2023FY 暫定値」のように確定・暫定が書いてある。

| 列コード | 内容 |
| --- | --- |
| 100 / 150 | 石炭 / 石炭製品 |
| 200 / 250 | 原油 / 石油製品（250A–C はその内訳） |
| 400 / 450 | 天然ガス / 都市ガス |
| 500 | 再生可能・未活用エネルギー |
| 550 / 600 | 事業用水力 / 原子力（常に 0） |
| 700 / 800 | 電力 / 熱 |
| 900 | 合計（最終エネルギー消費。非エネルギー利用を含む） |
| 910 / 920 | うちエネルギー利用 / 非エネルギー利用 |
| 940 / 960 | 電力寄与損失 / 産業蒸気・熱寄与損失 |
| 999 | 電力・熱配分後消費（= 910 + 940 + 960。非エネルギー利用を含まない） |

| 行コード | 内容 |
| --- | --- |
| 500000 | 最終エネルギー消費（合計） |
| 610000 / 620000 / 650000 | 農林水産鉱建設業 / 製造業 / 業務他（第三次産業）。子に中分類の業種がある |
| 700000 | 家庭 |
| 800000 | 運輸（旅客・乗用車のみ） |
| 950000 | 非エネルギー利用（燃料別の内訳がある。部門の行に含まれている再掲） |

### 指標シート

1 人あたりブロックの 12 行目が人口、14 行目が最終エネルギー消費（電力・熱配分後）の GJ/人。列 G 以降が年度。

## 3. 配信データ

`public/data/energy.json` の 1 ファイル。型は `src/app/data/cube.ts` の `EnergyJson`。

| キー | 次元 | 単位 |
| --- | --- | --- |
| `sector` | basis(2) × area(48) × year(19) × item(5) | PJ |
| `source` | basis(2) × area(48) × year(19) × item(8) | PJ |
| `industry` | basis(2) × area(48) × year(19) × item(29) | PJ |
| `population` | area(48) × year(19) | 人 |

- `basis`: `final`（最終エネルギー消費、列 900）と `allocated`（電力・熱配分後、列 999）。
- `area`: `00` は 47都道府県計（県の和）、`01`–`47` は県コード。ラベルは JIS X 0401 の正式名（「東京都」「大阪府」など）。表のラベルは略称なので、略称が正式名の先頭に一致することを確かめて置き換える。
- `year`: 1990, 2005, 2007–2023。`provisional` が暫定値の年度（2023）。
- 部門の項目: 農林水産鉱建設業、製造業、業務他（第三次産業）、家庭、家庭の乗用車。
- 中分類の項目: 農林水産鉱建設業・製造業・業務他の子の業種 29 個。各項目の `parent` が親の部門。ラベルは表のまま（全角空白を除き、半角中黒を全角にそろえる）。地図ビューだけで使う。
- エネルギー種の項目: 石炭・石炭製品、石油・石油製品、天然ガス、都市ガス、再生可能・未活用、電力、熱、発電・熱供給の損失（配分）。
  - 最終消費は合計行（500000）の各列。損失は 0。
  - 配分後は「合計行 − 非エネルギー利用行（950000）」の各列に、損失 = 940 + 960 を足す。和は列 999 に一致する。
- 値は TJ を 1000 で割って PJ にし、小数 3 桁に丸める。

## 4. 検証

`npm run data`（`scripts/build_data.py`）が失敗させる条件（47 県 × 19 年度すべて）:

- 部門の和が合計（列 900 / 999）と一致しない
- エネルギー種の和が合計（列 900 / 999）と一致しない
- 列 999 ≠ 910 + 940 + 960
- 事業用水力・原子力の列が 0 でない
- 列 999 の合計を人口で割った値が、指標シートの GJ/人 と一致しない
- 中分類の和が親の部門と一致しない（列 900 / 999）、中分類の並びが県によって違う
- 表の県名ラベルが正式名の先頭に一致しない
- 県によって年度や暫定値の年度がそろっていない、県コードが 01–47 でない

`npm run verify`（`scripts/verify.ts`）は配信 JSON を読んで確かめる:

- 地域が 47都道府県計 + 47、年度が 1990, 2005, 2007–2023、暫定値が 2023
- 値の数が次元の積に等しく、欠測が無く、非負（丸め幅を除く）
- 県名が正式名（例: `13` が東京都）
- 47都道府県計が県の和、部門の和がエネルギー種の和に等しい（中分類も同じ）
- 中分類の `parent` が部門の項目で、中分類の和が親の部門に等しい
- 最終消費では損失（配分）が 0
- 東京都 2023 年度の配分後 1 人あたりが指標シートの 67 GJ/人 前後
